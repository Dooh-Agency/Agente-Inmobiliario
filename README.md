# Agente Inmobiliario

Copiloto operativo SaaS para agentes inmobiliarios — un producto de [DOOH](https://dooh.com.ar).

Unifica contactos, conversaciones, seguimientos, visitas y oportunidades en un solo lugar. La IA clasifica, prioriza y sugiere; el agente aprueba y decide.

## Documentación

- [`docs/producto.md`](docs/producto.md) — documento de producto: problema, propuesta de valor, alcance funcional, arquitectura, roadmap, costos y modelo de negocio. Es la fuente de verdad del proyecto.
- [`AGENTS.md`](AGENTS.md) — contexto e instrucciones para asistentes de IA (Claude Code, Codex CLI u otro) que trabajen en este repo.
