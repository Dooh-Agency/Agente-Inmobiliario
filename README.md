# Agente Inmobiliario

Copiloto operativo SaaS para agentes inmobiliarios — un producto de [DOOH](https://dooh.com.ar).

Unifica contactos, conversaciones, seguimientos, visitas y oportunidades en un solo lugar. La IA clasifica, prioriza y sugiere; el agente aprueba y decide.

## Documentación

- [`docs/producto.md`](docs/producto.md) — documento de producto: problema, propuesta de valor, alcance funcional, roadmap de fases, costos y modelo de negocio. Es la fuente de verdad del proyecto. También existe como [`docs/producto.html`](docs/producto.html), una versión renderizada para compartir fuera de un editor de markdown.
- [`docs/arquitectura.md`](docs/arquitectura.md) — arquitectura técnica: stack, capas de la aplicación, modelo de datos, entornos y CI/CD.
- [`docs/roadmap-tecnico.md`](docs/roadmap-tecnico.md) — versiones técnicas (V0 a V1.x) que implementan las fases de producto, con entregables y criterio de salida de cada una.
- [`docs/adr/`](docs/adr/README.md) — registro de decisiones de arquitectura (ADRs): framework, backend, multi-tenancy, UI, testing, CI/CD y más, cada una con las alternativas evaluadas.
- [`AGENTS.md`](AGENTS.md) — contexto e instrucciones para asistentes de IA (Claude Code, Codex CLI u otro) que trabajen en este repo. Punto de partida obligatorio antes de tocar código o documentación.
